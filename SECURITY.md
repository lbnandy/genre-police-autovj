# Security policy

## Supported versions

The current `0.1.x` Beta release receives security and dependency updates. Older development snapshots are not supported.

## Reporting a vulnerability

Use GitHub private vulnerability reporting when it is available for this repository. If private reporting is unavailable, open an issue asking for a private contact channel without publishing exploit details.

Do not include local audio, library exports, diagnostic files containing information you do not intend to share, or any credentials in a public issue.

For ordinary bugs and feature requests, use the repository Issues page and include the application version, Windows version and reproduction steps.
